从开始工作到现在已经八年了，记一下流水帐。


2018 年 6 月份，我开始找实习。6 月份并不是互联网大厂招实习生的时间，大厂都没有发面试机会。
在 V2EX 上看到招实习生的广告，于是去面试了下厨房 ( xiachufang.com )，并拿到了实习 offer。

下厨房的面试过程非常简单，只有两次电话面试，在我去办公室之前他们都不知道我是什么样子。

回过头来看下厨房的工作氛围算是数一数二的，技术团队精简又高效，同事之间的氛围非常好。
feichao 的个人魅力可以兜住二三十位工程师，我从来没见过能同时管理这么多人的 manager。
ushuz 是第一个在办公室用三屏的人，是我认知中的黑客的样子，写了一套部署脚本和一些基础代码。读他的代码让我第一次了解搞基建类型的程序员。
cadl 顶着萌娘百科的 badge，用着 emacs。肯定是位大佬，但不清楚在什么圈子里。
黑瞎子和 x1ah 是负责带作为实习生的我，在我刚来的时候 x1ah 去懒饭项目了。黑瞎子是我职业生涯中第一位同事。
此外还有和我同期的两位前端实习生：一位想去东南亚菠菜网站赚钱，不知道现在过的怎么样。另一位似乎去了阿里，让我印象最深的是他会随身带一台 Sony 相机。

在下厨房的工作算是轻松惬意，业务部门没有不合理需求，工作强度不高（也多亏了 feichao 会拒绝离谱的业务需求），Python 的编码效率也极高，一度让我产生了这个行业不加班的幻觉。
头三个月是实习生的活，后面需求以现在的角度看都不像是实习生应该做的事情了。这里非常感谢 feichao 的认可。比如 [如何滥用 protobuf](https://blog.sasa.su/diary/how_to_abuse_protoc/) 就是当时的工作，我还拜此写了一些 Object-C。

实习的最后几个月我接了京东的校招 offer，下厨房的 retrun offer 也就没接。
颇有一点世界很大我想去看看的样子。


2019 年 6 月份，以应届生身份入职京东。部门是京东云的内部监控 (ark.jd.com)，不过这个部门大概率已经不在了，介绍部门特点意义也不大。
京东云的工作环境算是比较紧张但可以接受的，早上九点半需要打卡，但补卡 leader 会一定会批。晚上则是会要求 995，leader 会非常无奈地要求大家参与一些没意义的会议来拖延下班时间。

最先带我的是 qudongfang 和一位天津 Java 程序员（抱歉记不住名字），但是很快 qudongfang 跳槽去了 mongodb 的欧洲部门做售后，另一位则是因为家庭原因离职。我被迫接下了两个人遗留的全部工作。
遗留工作基本上是责任较大但成果不多的清理任务，感谢 flyan 的认可，这些事情做完后把我调到了存储组（同时略过了转正述职），负责存时序数据。从此我的职业生涯算是正式开始。

我刚进存储组半天，负责带我的 ipush 就和 flyan 提了离职。[这条帖子](https://www.v2ex.com/t/954271) 里的内容就是当时存储组的工作，我发现这个帖子时还去发邮件叙旧了一下。
感谢 ipush 给我讲了很多存储系统的基本原理，在 ipush 离职之后我就对 ES 的存储结构做了一次大改，去掉了一个 nested 字段，把 `[{"key":"AAA", "value":"BBB"}]` 变成了 `["AAA=BBB"]`。把 nested term 变成了 prefix 查询。
这个改动成功的把几百台 ES 压缩成了十几台 ES，同时彻底杜绝了 ES 过载。
我的一些做事风格就是从 ipush 上学来的，2023 年他说的「大概等于 4-5 年经验重复了两遍」我感觉也是很多人的现状。京东的服务器量级即便是跨国企业也很难达到，有一整层楼的服务器都在运行自己的程序根本无法想像。

在这个时候 flyan 把我调去参加云监控的 APM 项目，我需要使用 flink 来计算一些跨机器的链路追踪，[写出无入侵的链路追踪 go sdk 是不可能的](https://blog.sasa.su/diary/fuck_go_stack_management/) 就是当时的工作。
在这里我和前端同学闹了点矛盾，产品同学搞了近 30 个监控指标，按照前端同学的工作流程这是 30 个需求，而我将二阶段聚合放在查询的时候做，要求前端同学给我传一个计算参数。
比如要对 CPU 使用率算 15 秒的平均值，前端认为应该有一个指标名叫 `cpu_avg`，而我则是给出两个指标 `cpu_sum` 和 `cpu_cnt`，要求前端传参为 `cpu_sum/cpu_cnt`
在会上吵了一架，我当时还哭了。flyan 的调解方式是我给出一个 json 文件供前端查表。这算是我生涯中第一次与同事闹冲突。

在不久之后那位前端同学就离职了，现在看来他只是不想接这种活而已。

在我一切完工后云监控 APM 也没有上线。项目被战略取消了。

我回到存储组之后遇到北京因为疫情封城，大家工作积极性不高。但我在家又没事干每天起床就是写代码。几个月时间我把时序数据库的执行器从行算改成了列算，性能有数十倍的提升（当然也是因为 Go 语言本身有一些问题）。
尝到甜头之后我又花了一个月时间删除了写入数据时所有的内存分配，性能也有数十倍提升。

优化做完了却卡在上线，我和 flyan 谈话了一次，flyan 不建议我离职，建议我去找个业务需求，由业务驱动的代码变更话语权较高。

但没过多久 flyan 也离职了，据说是偷偷去字节跳动又把云平台做了一边。


这时候存储组就我一个人了，我也彻底摆脱束缚，在宗城浩的建议下开始做冷存储。这期间写了一些[关于存储格式的文章](https://blog.sasa.su/diary/timeseries_on_disk_format_2/)

随后冷存储以手动运行的方式投入使用，基本上做到了 20 倍的数据压缩。以前一个月就存满了的硬盘现在可以存数年。还可以存到各种冷存储上去，我个人感觉是相当好用。


但好景不长，在我狂写代码的时候管理层有变动，京东云老板连续换了两次，京东云变成京东金融的子部门。
内部监控平台开始要求盈利，周围的人也快速离职。我提离职的原因已经记不住了，只记得宗城浩和我谈了很久，错过了午饭时间，请我吃了一顿饺子。
然而这顿饺子并没有改变我辞职的想法。


我基本上算是裸辞，辞职的同时开始找工作。

头条的 rockeet 旗下的存储组，面试这位的时候我几乎没准备，面试解题的思路实在是太巧妙，我相信你们的产品一定很强。https://topling.cn/ 虽然你们也出来创业了....

NebulaGraph，一面的大老板觉得我可以，但是二面时依旧没准备，没做出来标准面试题....

蚂蚁金服因为工作年限不够，达不到社招的等级，这里感谢 阿丹(killme 6115) 和 fengjiachun 和 HR 讨论定级，虽然 2022 年你们也出来创业了....

万里开源 Offer 到手了但是没敢去，当初面试时画饼的产品在 24 年上线，名叫 [Rapid 引擎](https://greatsql.cn/blog-10-1429.html) 从 26 年往回看这家反而是最靠谱的。

选择的 Offer 是 VMware 的 Greenplum，manager 是著名的牛街程序员 cmulong https://m.36kr.com/p/1030133247018754

早在 2018 年我在看硅谷美剧时就读过这片文章，后续能一起工作纯属偶然。
「他做了16年的程序员，没当上过管理层，没拿过那种数十个月的年终奖。」然而，当程序员的第 18 年也成为了 Manager。

在 VMware 的时期基本上算最快乐的时间段，就这么过了 4 年。

但是好景不长，2023 年 11 月博通收购 VMware，并迅速裁员 3 轮，最开始 VMware 百人的团队最后剩下了不到 10 个人。

Broadcom 花了 2 年时间把 VMware 的东西全部吃下，外界能看到的东西大概只有产品从买断制改成订阅制和涨价。但内部管理风格其实变动很大。

Broadcom 内部形式主义非常严重，我只能管中窥豹，从一些现象来分析一下企业风格。

博通方面要求每个季度进行一次发布，不能推迟：
增加了 code freeze，但实际上 code freeze 是禁止合并任何代码，这导致发布周期事实上提前了。
禁止 engineer 自己创建任务，所有任务都需要 VP 审批才能分配人力。

博通只在乎大客户，对每一个大客户丢失进行问责：
大家不在乎增量，没有实用的新功能了。
无论怎么做都无法让管理层满意，大家会开始避免做任何事。
管理层实际上也不知道要做什么，只是无意义向下层施压。

然后是 Manager 的变动，新的 Manager 能力不强，善于对每件事双向加压，对要做的事情没有规划。在裁员这么多之后留下的 Manager 肯定是符合企业文化的，从 Manager 的行为也可以分析企业风格。

要求在早上9-10点立刻回复他的所有消息。
基本上什么事都不干，直到 code freeze 前两周开始催，无论进度如何。
把同样的事做四边，收到任务后回复消息说收到，完成后回复消息说完成，每天有日报，每周有周报。
技术嗅觉极差，经常安排一些收益不高看不到效果又极其复杂的事情，比如将单个 repo 迁移到 mono repo，同时还有增加一条单独的 CI 入口给被迁移的代码。
在跨部门的沟通中主动为自己团队创造不利局面。

因为裁员人数过多，有一些竞争对手直接把所有被裁的收走，用原班人马组建一个新的公司。
比如 2025 年初的 Cloudberry 和 2025 年末的 WarehousePG。最大的竞争对手是自己制造的我也是第一次见。

总体看来被博通收购的软件公司会失去活力，现在还能拉住我不离职的也就只有股票了。
